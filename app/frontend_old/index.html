About the System

Built for Real-World Logistics Intelligence

The Olist Risk Predictor is an end-to-end machine learning pipeline that flags high-risk shipments at the moment of order placement — before dispatch, before customer dissatisfaction.

🎯

The Problem

A significant share of Olist shipments face carrier delays. Without early signals, operations teams can only react — not prevent. Customer trust suffers and refund costs rise.

💡

Our Solution

An ML classifier trained on 99k real anonymized orders (2016-2018) that computes 44 features from raw order data and returns a Late Delivery Risk score in real time.

🚫

Leakage-Free

All post-dispatch data (carrier pickup, actual delivery, review scores) is strictly excluded — ensuring the model is truly usable at checkout, not just in hindsight.

Key Features

What Makes This System Powerful

A fully automated pipeline from raw order data to actionable risk intelligence.

🗺

Geospatial Distance Engine

Automatically computes Haversine distance between customer and seller coordinates using 5-digit ZIP prefix lookup tables.

Distance & Geo
⏱

Lead-Time Modelling

Derives estimated shipping window, approval lag, and historical seller dispatch speed — all from order-time data only.

Time Features
📦

Package Volumetric Analysis

Computes cubic volume, weight-to-size ratio and freight-to-price ratio to encode physical shipment characteristics.

Product Features
🧠

MLP Neural Network Core

A Multi-Layer Perceptron trained and validated on 99k+ real orders — achieving 0.7766 ROC-AUC with strict temporal separation.
